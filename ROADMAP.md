# BORZO — план «оживления» (внутрянка)

Каркас (16 экранов) готов. Теперь делаем систему рабочей. Идём сверху вниз по меню.
Правило: делаю всё до точки, где нужен Руслан (API-ключ / сервер / загрузка Excel) — там оставляю готовую ячейку и помечаю 🔴.

## Этап 0 — Фундамент (без Руслана) ✅ в работе
- [x] store.js — локальный слой данных (localStorage), seed-данные, pub/sub. Позже бэкенд подменяется без переделки UI.
- [x] Настройки → Интеграции (integrations.html) — ЯЧЕЙКИ под API-ключи: Мой Склад, Trello, Kaspi, WhatsApp, Instagram/Meta и др. Сохраняются локально, статус «не подключено». Это площадка Руслана.
- [x] Модалки, тосты, общие интерактивные компоненты.

## Этап 1 — CRM живой (стартовый блок)
- Канбан из данных, перетаскивание сделки между этапами, добавить/редактировать/удалить сделку, поиск и фильтры работают, выбор сделки → карточка, всё сохраняется.

## Этап 2..N — вниз по меню
Клиенты · Каталог · Производство · Склады · Снабжение · Отгрузки · Финансы · Аналитика · Документы · Отчёты · Сотрудники · Маркетинг · SMM.
Каждый: рендер из store, рабочие формы/фильтры/поиск, связи между разделами (продал стол → списание склад → задача производству — по мере готовности данных).

## 🔴 Точки, где нужен Руслан (готовим площадку, не делаем молча)
1. API-ключи в Настройках (когда будет сервер): Мой Склад (перенос номенклатуры/остатков), Trello (база отгрузок), Kaspi, WhatsApp, Instagram.
2. Excel по финансам — Руслан загружает файлы / даёт задания на заполнение.
3. Сервер + домен — для реального развёртывания и доступа сотрудников по ссылке, вход по логину/ролям.

## Стратегия миграции данных
Мой Склад и Trello → через API тянем в параллель. Старое продолжает работать, новое наполняется. В момент готовности перерубаем на BORZO-систему.
