# BORZO — мозг ИИ-агента-продавца (переносимый пакет)

Собран 27.09.2026 из анализа реальной выгрузки переписок (borzo_messages, 32 xlsx, 54 131 сообщение, 4 125 клиентов, март–сентябрь 2026).

## Файлы (это всё — ДАННЫЕ, не код; переносятся на любое ядро)
- `AGENT-PROMPT.md` — системный промпт (персона + факты о товаре + воронка + возражения + правила). Это то, что ядро подаёт LLM как system.
- `AGENT-EXAMPLES.md` — реальные примеры диалогов и оборотов (few-shot), как заходят клиенты и как отрабатывать.
- Скрипты продаж — отдельно, в базе CRM (таблица `crm_scripts`, магистраль + инструменты). Тоже данные.

## Как это работает и почему переносимо
Мозг агента = промпт (эти .md) + скрипты (в БД) + фото-арсенал (позже) + коррекции Ульяны (позже). Всё — текст/данные, НЕ привязаны к конкретному движку.

Когда проект переедет на другое ядро Руслана: эти файлы и таблица crm_scripts переносятся как есть. Новое ядро подставляет СВОЙ тонкий слой «вызов LLM» (один HTTP-запрос к нейросети с этим system-промптом + контекстом переписки) — и агент работает там же, без переделки мозга. Ноль привязки к серверу borzopult.

## Как включать (после переезда WhatsApp)
1. Тумблеры агента уже есть в CRM (глобал/воронка/чат). По умолчанию выкл.
2. Первый этап полномочий — только «Входящий старт» (первый ответ клиенту), очень аккуратно.
3. Убедились, что в адеквате → расширяем полномочия по воронке.
4. Обучение вживую: Ульяна видит косяк → правит/наговаривает → правка ложится агенту (пульт-тренер, отдельная стройка).
